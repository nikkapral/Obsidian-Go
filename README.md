# Obsidian Check

Квиз по вашим заметкам Obsidian на телефоне. Плагин генерирует из заметок утверждения «верно/неверно» (через Kimi API), приложение показывает их карточками: свайп вправо — верно, влево — неверно.

## Как устроено

```
Obsidian (плагин)  →  Wi-Fi  →  Телефон (Expo)
читает заметки,             выбираете колоду,
генерирует карточки,        свайпаете,
отдаёт по локальному API    видите счёт
```

Плагин видит **только папки, которые вы сами указали** в настройках. Остальные заметки (пароли, личное) не читаются и не отправляются никуда.

## Установка плагина

1. Скопируйте `plugin/main.js` и `plugin/manifest.json` в `<ваш vault>/.obsidian/plugins/obsidian-check/`
2. Obsidian → Настройки → Community plugins → включите **Obsidian Check**
3. В настройках плагина заполните:
   - **Kimi API key** — ключ с https://platform.moonshot.ai
   - **Tracked paths** — папки для квиза, по одной на строку, например:
     ```
     История
     Английский/Слова
     ```
4. Команда (Ctrl+P) → **Regenerate all decks** → дождитесь уведомления

## Приложение

```bash
cd app
npx expo start
```

1. Откройте в Expo Go (телефон и компьютер в одной Wi-Fi)
2. В настройках введите IP компьютера, например `192.168.1.5:27124`
3. Выберите колоду → свайпайте: **→ верно, ← неверно**
4. В конце — счёт и разбор ошибок с правильными ответами

## Обновление карточек

Изменили заметки → в Obsidian снова «Regenerate all decks». Устаревшие колоды в приложении помечаются «можно обновить».

## Если не работает

- **«Obsidian недоступен»** — Obsidian не запущен, неверный IP, или телефон не в той Wi-Fi
- **Ошибка генерации (Kimi)** — проверьте ключ и баланс на platform.moonshot.ai; кеш при ошибке не затирается
- Проверка сервера с компьютера: `curl http://localhost:27124/decks`
